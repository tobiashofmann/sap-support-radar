# Security Policy

## Supported Versions

The project is continuously built. Only the latest release is supported.

## Scope

If you believe you've found a genuine vulnerability specific to this app's own code please report it as below.

If the issue instead lives in one of the used frameworks itself, please report it upstream.

## Reporting a Vulnerability

Please report security issues privately via
[GitHub's private vulnerability reporting](https://github.com/tobiashofmann/sap-support-radar/security/advisories/new)
rather than opening a public issue.

Include:

- A description of the issue and its potential impact.
- Steps to reproduce (sample PAM/own-products JSON, if relevant).
- Any suggested fix, if you have one.

This is a solo/hobby project without a dedicated security team and no guaranteed SLA, but reports will be acknowledged and triaged possible.
